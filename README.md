# 영화 추천 및 관리 시스템

C 언어로 구현한 콘솔 기반 영화 추천 및 관리 프로그램입니다. 사용자는 회원가입과 로그인을 통해 영화 목록을 확인하고, 영화 상세 정보 조회, 키워드 검색, 평점 등록을 할 수 있습니다. 관리자는 별도의 관리자 계정으로 로그인해 영화 정보를 추가, 수정, 삭제할 수 있습니다.

프로그램 데이터는 별도의 데이터베이스가 아니라 CSV 파일로 저장됩니다. 따라서 C 언어의 구조체, 파일 입출력, 문자열 처리, 메뉴 기반 콘솔 UI를 함께 학습하기 좋은 프로젝트입니다.

## 프로젝트 목표

- C 언어 기반 콘솔 프로그램으로 영화 관리 시스템을 구현합니다.
- 회원과 관리자를 구분해 서로 다른 기능을 제공합니다.
- 영화 정보, 사용자 정보, 리뷰 정보를 CSV 파일로 저장하고 불러옵니다.
- 사용자가 원하는 영화를 빠르게 찾을 수 있도록 목록, 상세 보기, 검색 기능을 제공합니다.
- 영화 평점을 기록해 사용자 참여형 영화 시스템의 기본 구조를 실습합니다.

## 주요 기능

### 사용자 기능

- 회원가입
- 로그인
- 전체 영화 목록 조회
- 영화 상세 정보 확인
- 영화 제목 또는 장르 기반 키워드 검색
- 영화 평점 등록
- 로그아웃

### 관리자 기능

- 관리자 로그인
- 영화 추가
- 영화 정보 수정
- 영화 삭제
- 영화 데이터 CSV 저장

### 파일 저장 기능

- 사용자 정보 저장: `user.csv`
- 영화 정보 저장: `movie.csv`
- 평점 기록 저장: `review.csv`
- 관리자 작업 로그 파일: `admin_log.csv`

프로그램은 `Movie`, `User` 구조체를 사용해 영화와 사용자 정보를 메모리에 저장합니다.

```c
typedef struct {
    int id;
    char title[50];
    char genre[20];
    int release_year;
    char director[50];
    float ratings[MAX_RATINGS];
    char rating_users[MAX_RATINGS][20];
    int rating_count;
} Movie;
```

```c
typedef struct {
    char username[20];
    char password[20];
} User;
```

## CSV 파일 형식

### `movie.csv`

영화 기본 정보를 저장합니다.

```csv
영화ID,영화 제목,장르,개봉 연도,감독
1,더 마블스,액션,2023,니아 다코스타
2,오펜하이머,드라마,2023,크리스토퍼 놀란
```

### `user.csv`

회원가입한 사용자 계정 정보를 저장합니다.

```csv
s123,s1234
x123,x1234
c123,c1234
```

### `review.csv`

사용자가 영화에 입력한 평점을 저장합니다.

```csv
1,v123,3.5
1,c123,3.5
```

각 열은 `영화 ID, 사용자 ID, 평점`을 의미합니다.

## 실행 방법

### Visual Studio에서 실행

1. 저장소를 클론합니다.

```bash
git clone https://github.com/kimayeong21/movie-system-c.git
cd movie-system-c
```

2. Visual Studio에서 `창업프로젝트/창업프로젝트.vcxproj` 파일을 엽니다.
3. 시작 파일이 `영화추천프로그램.c`인지 확인합니다.
4. 빌드 후 실행합니다.
5. 프로그램 실행 위치에 `movie.csv`, `user.csv`, `review.csv`가 있어야 정상적으로 데이터를 불러올 수 있습니다.

### 명령어로 컴파일하는 경우

GCC가 설치되어 있다면 다음과 같이 컴파일할 수 있습니다.

```bash
cd 창업프로젝트
gcc 영화추천프로그램.c -o movie_system
./movie_system
```

Windows PowerShell에서는 실행 파일 이름이 다음처럼 보일 수 있습니다.

```powershell
.\movie_system.exe
```

> 한글 파일명과 한글 CSV 데이터가 포함되어 있으므로 Windows 환경에서는 Visual Studio 실행을 권장합니다.

## 기능 상세

### 회원가입

사용자가 아이디와 비밀번호를 입력하면 메모리에 계정이 추가됩니다. 프로그램 종료 시 `user.csv`에 저장됩니다.

### 로그인

입력한 아이디와 비밀번호를 `user.csv`에서 불러온 사용자 목록과 비교합니다. 로그인에 성공하면 영화 목록 화면으로 이동합니다.

### 영화 목록 조회

`movie.csv`에서 불러온 영화 목록을 ID, 제목, 개봉 연도, 장르와 함께 출력합니다.

### 영화 상세 보기

영화 ID를 입력하면 제목, 장르, 개봉 연도, 감독, 평가 내역을 확인할 수 있습니다.

### 영화 평가

영화 ID와 평점을 입력하면 해당 영화의 평점 배열에 저장되고, `review.csv`에도 기록됩니다. 평점은 `1.0`부터 `5.0`까지 입력할 수 있습니다.

### 영화 검색

입력한 키워드가 영화 제목 또는 장르에 포함되어 있으면 검색 결과로 출력합니다.

### 관리자 영화 관리

관리자는 영화 제목, 장르, 개봉 연도, 감독 정보를 입력해 새 영화를 추가할 수 있습니다. 기존 영화 ID를 기준으로 수정 또는 삭제도 가능합니다.

## 현재 구현상의 특징

- 영화와 사용자는 고정 크기 배열로 관리됩니다.
- 최대 영화 수는 `100개`, 최대 사용자 수는 `50명`, 최대 평점 수는 영화당 `100개`입니다.
- 영화 검색은 `strstr()`를 사용한 단순 키워드 포함 검색입니다.
- 비밀번호 출력 시 첫 글자만 보이고 나머지는 `*`로 표시됩니다.
- 영화 추가, 수정, 삭제 시 `movie.csv`에 즉시 저장됩니다.
- 프로그램 종료 시 사용자와 영화 데이터를 다시 저장합니다.

## 주의 사항

- 현재 비밀번호는 암호화하지 않고 CSV에 평문으로 저장됩니다.
- 회원가입 시 중복 아이디 검사는 구현되어 있지 않습니다.
- 공백이 포함된 영화 제목이나 감독명은 `scanf("%s", ...)` 입력 방식 때문에 직접 입력 시 한 단어까지만 받을 수 있습니다.
- `movie.csv`에는 공백이 포함된 영화 제목이 저장되어 있지만, 새로 입력하는 데이터는 공백 처리에 제한이 있습니다.
- 리뷰 데이터는 `review.csv`에 저장되지만, 프로그램 시작 시 기존 리뷰를 다시 불러오는 로직은 현재 구현되어 있지 않습니다.
- `admin_log.csv` 파일은 존재하지만 현재 메인 코드에서는 관리자 작업 로그 저장 로직이 연결되어 있지 않습니다.
